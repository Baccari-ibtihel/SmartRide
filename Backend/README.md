# SmartRide Backend — Branche `ibtihel`

Ce dossier contient l'implémentation individuelle de **Ibtihel Baccari** :
* **`dashboard-service`** : Le microservice métier (Module 7).
* **`api-gateway`** : Passerelle Spring Cloud avec routage vers le Dashboard.
* **`discovery-server`** : Serveur de découverte Netflix Eureka.

Chaque service dispose de son code source Maven et de son Dockerfile respectif pour un déploiement conteneurisé.
